### Project Description
PimpleDetector3000 is a real-time facial skin and pimple detection web application powered by MediaPipe and colour grading/image analysis.

The application uses facial detection to first check whether a clear face is visible in the camera. Once a suitable face is detected, it focuses on the relevant facial skin region and analyses colour variations to identify potential pimples or spots.

If the camera is showing something other than a face, or if the face is too unclear for reliable analysis, the application asks the user to show their face more clearly before continuing.

The project was built to be simple, interactive, user-friendly, and slightly unnecessary.
